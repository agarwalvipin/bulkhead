⚡ Auto-Loading

Skills automatically load based on project context:

pyproject.toml → languages/python.md
fastapi in deps → frameworks/fastapi.md
tsconfig.json → languages/typescript.md
Phase 3 active → practices/security.md

💻 Usage Commands

/bulkhead skills

List all available skills + auto-detected ones for your project

/bulkhead skill python

Load Python patterns, typing, and async best practices

/bulkhead skill security

Load OWASP guidelines and security best practices

📍 Phase Integration

Skills are automatically considered during relevant phases:

Phase Relevant Skills Purpose
Phase 2: Design architecture/* Architectural patterns for system design
Phase 3: Security practices/security.md OWASP, threat modeling guidance
Phase 6: Execute languages/*, frameworks/* Implementation patterns and conventions
Phase 7: Verify practices/testing.md Testing strategies and validation

📄 Skill File Format

Each skill file uses YAML frontmatter for metadata:

---
description: Python patterns, typing, async
category: languages
auto_load:
  - when: "pyproject.toml"
    in: ["files"]
related_skills:
  - practices/testing.md
---

🛠️ Creating Custom Skills

1

Create the file

Add a .md file in the appropriate category.

.bulkhead/skills/frameworks/react.md
2

Add YAML frontmatter

Include description, category, and optionally auto_load rules.

3

Document the expertise

Add Overview, Key Patterns, Anti-patterns, Code Examples, and References sections.

4

Update the category index

Add your skill to the category's _index.md file.
