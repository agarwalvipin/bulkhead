SCENARIO 1

New Feature Development

Complete 8-phase governance flow for standard feature development.

Quick Start

# Just start here - the orchestrator handles everything
/bulkhead

The smart orchestrator will detect your project state and guide you through the appropriate phase.

Workflow Steps

1

Start Project

Initialize the workflow.

  • Run /bulkhead
  • Select [1] Start new SDLC workflow (if starting fresh)
  • Or [1] Continue to Phase <N+1> (if work in progress)
2

Follow the Flow

Complete the governance phases artifacts.

  • Triage: 00-triage.json
  • Context: 01-context.json
  • Design: 02-design.json
  • Security: 03-security.json
  • Decision: 04-decision.md (Human Gate)
💡 Pro Tip: After completing each phase artifact, just type /bulkhead again.
3

Execution & Verification

Code, test, and finish.

  • Select [1] Continue to ensure you are on the correct branch
  • Implement feature and update 06-report.md
  • Run tests and update 07-verify.md
  • Run /bulkhead to see Post-Completion Menu
