SCENARIO 1

New Feature Development

Complete 8-phase governance flow for standard feature development.

Quick Start

# 1. Start Standard Flow
/bulkhead start

# 2. Planning
/phase-epic-orchestrator start P1
/int-github-project create-epic "New Feature"

# 3. Execution
/phase-6-execute

Workflow Steps

1

Governance Gates (Phases 0-4)

Establish viability and safety before coding.

  • Triage: Worth the cost? (/phase-0-triage)
  • Context: Blast radius? (/phase-1-context)
  • Design: Architecture? (/phase-2-design)
  • Security: Threats? (/phase-3-security)
  • Decision: Go/No-Go? (/phase-4-decision)
2

Planning & Tracking

Break down tasks and checkpoint.

  • Generate tasks (/phase-5-plan)
  • Sync to GitHub (/int-github-project)
  • Verify artifacts (/phase-checkpoint)
3

Execution & Verification

Code, test, and merge.

  • Implement feature (/phase-6-execute)
  • Run tests (/phase-7-verify)
  • Create PR (/int-pr-manager)
