Emergency Hotfix

P0 CRITICAL

Rapid response protocol for critical incidents.

Quick Start

/phase-0-triage --critical

# 2. Fast-Track Context
/phase-1-context --fast-track

# 3. Execution

Condensed Workflow

1. Fast-Track

Phases 0-2 compressed into single context pass.

2. Minimal Fix

Implement fix only. No refactoring.

3. Verification

Automated tests MUST pass. Manual testing abbreviated.

⚠️ RESTRICTIONS

Infrastructure changes (INFRA-5) are NOT eligible for fast-track.
Network, Firewall, and IAM changes must go through full Phase 3 Security review.
