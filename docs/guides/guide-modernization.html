SCENARIO 2

Legacy Modernization

Comprehensive flow for analyzing, refactoring, or rebuilding legacy systems.

Quick Start

# Start modernization workflow
/bulkhead

Select [2] Plan large modernization project from the Start Menu.

Workflow Steps

1

Analysis Phase

Understand the current state.

  • The workflow scans codebase to generate modernization-plan.json
  • Decision Matrix: Evaluates Rebuild vs Refactor based on:
    • Tech Debt metrics
    • Complexity scores
    • Test coverage
2

Execution Paths

Path A: Rebuild

Greenfield replacement.

  1. Run /bulkhead
  2. Select [1] Start new SDLC workflow
  3. Follow standard 8-phase SDLC

Path B: Refactor

Strangler Fig pattern.

  1. Run /bulkhead
  2. Select [2] Continue current epic
  3. Extract component & route traffic
3

Validation

Ensure parity.

  • Parity Testing: Run shadow traffic
  • Cutover: Switch primary traffic
  • Cleanup: Delete legacy code

Key Artifacts

Artifact Purpose
modernization-plan.json Master map of the system.
rebuild-scorecard.md Justification for decision.
refactoring-plan.md Extraction guide (if refactoring).
