SCENARIO 3

Security-First Infrastructure

Strict protocol for infrastructure and security-critical changes.

Quick Start

# Start governance workflow
/bulkhead

Select [1] Start new SDLC workflow and mark Triage classification as MAJOR or CRITICAL.

Critical Rules (INFRA)

INFRA-1: No Defaults

Explicitly declare all ports, creds, and nets.

INFRA-2: Threat Model

03-security.json is MANDATORY.

INFRA-3: Decision Record

Signed 04-decision-record.md required.

INFRA-5: No Fast-Track

Network changes are P0 security events.

Workflow Steps

Step 1

Design Review

Input: 02-design.json (IaC definitions).

  • Run /bulkhead and select Utilities.
Step 2

Threat Modeling

Analyze attack surface.

  • Output: 03-security.json
Step 3

Governance Gate

Human approval required.

  • If Risk is HIGH, work stops until mitigation.
  • Sign-off: Manually sign 04-decision.md
Step 4

Provisioning

Automated execution.

  • Run /bulkhead and select [1] Continue
  • Manual changes forbidden.
