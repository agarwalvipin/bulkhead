SCENARIO 3

Security-First Infrastructure

Strict protocol for infrastructure and security-critical changes.

Quick Start

# 1. Start Security Phase
/phase-3-security

# 2. Run Threat Model
/security-architect

# 3. Get Approval
/phase-4-decision

Critical Rules (INFRA)

INFRA-1: No Defaults

Explicitly declare all ports, creds, and nets.

INFRA-2: Threat Model

03-security.json is MANDATORY.

INFRA-3: Decision Record

Signed 04-decision-record.md required.

INFRA-5: No Fast-Track

Network changes are P0 security events.

Workflow Steps

Step 1

Design Review

Architects review 02-design.json for hardcoded secrets and defaults.

Step 2

Threat Modeling

Generate 03-security.json using STRIDE methodology via /security-architect.

Step 3

Governance Gate

Requires dual approval (Security + Infra) in 04-decision-record.md.

Step 4

Provisioning

Apply changes only after approval. No manual console clicks.
